# TILT — Privacy Policy

The published privacy policy for **TILT**, a free neon tilt-maze arcade game for Android
(`com.beaniedude.tilt`).

Live at <https://shreyesjishnu.github.io/tilt-privacy/>

This repository is public because Google Play requires the privacy policy URL to be reachable
with no sign-in. It holds only the policy page and its artwork. The game's source is elsewhere
and stays private.

If the policy changes, the date at the top of the page changes with it.
